components::button(id: impl Into<ElementId>, label: impl Into<SharedString>, disabled: bool) -> Stateful<Div>. Caller adds .on_click. Enabled buttons show a visible focus border and GPUI activates focused clicks with Enter or Space. Disabled buttons suppress mouse down and are removed from Tab order. Pinned GPUI stores chained click callbacks on Stateful<Div>, so this exact return type cannot guarantee suppression for every activation path after a caller adds .on_click. Callers must also gate their callback while disabled; the lead should approve a typed callback API for guaranteed gating.

components::variable_list::StableList stores measured heights keyed by media ID. StableList::new(estimated_px: f32) -> Self; set_items(&mut self, ids: &[i64]); measure(&mut self, id: i64, height_px: f32); visible(&self, offset_px: f32, viewport_px: f32, overscan_px: f32) -> Vec<VisibleRow>; total_height(&self) -> f32; anchor(&self, offset_px: f32) -> Option<(i64, f32)>; offset_for_anchor(&self, id: i64, inset_px: f32) -> Option<f32>. VisibleRow contains id, index, top_px and height_px. Unsaved row state belongs to Workspace, not StableList.

Multiline TextInput uses pinned GPUI shape_text wrapping and keeps cursor, selection and UTF-16 IME geometry aligned with visual rows. The scrollable input height stays 120px; the content grows with wrapped rows.
